💼 Projeto: Landing Page de Investimentos – CDB

Este projeto é uma landing page responsiva desenvolvida em HTML, CSS e Tailwind CSS, simulando um site de investimentos. Ele foi criado para praticar habilidades de desenvolvimento web fullstack, com foco em:

Design moderno e responsivo para desktop, tablet e mobile

Menu com dropdowns funcionais e botão “Acesse sua conta”

Seções de conteúdo com cards informativos, destacando modalidades de investimento

Integração com WhatsApp para contato rápido

Background visual impactante com imagens e cores temáticas

🛠 Tecnologias utilizadas:
HTML, CSS, Tailwind CSS, JavaScript (para menu mobile e dropdowns)

🎯 Objetivo:
Simular um site real de banco, aprimorando UX, responsividade e interatividade, preparando para projetos fullstack reais.
